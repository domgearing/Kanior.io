# Kanior.io
Create a transcript creation, processing, and query app that can record transcripts from expert calls and internal meetings, saves the transcripts locally and securely, and allows users to search for verifiable quotes directly from the transcripts themselves.

- [Data model](docs/DATA_MODEL.md)

- [Security contract](docs/SECURITY.md)
- [Schema generation and validation](schemas/README.md)
